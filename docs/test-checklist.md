# چک‌لیست آزمون / Test checklist

نسخهٔ ۱.۰.۱ — ۱۸ نوامبر ۲۰۲۶

## آزمون‌های خودکار

از پوشهٔ `noxaplus-website-business` اجرا کنید:

```bash
node --check js/main.js
node --check js/planner.js
node --check js/check-i18n.js
node --test tests/site.test.cjs
node js/check-i18n.js
```

- `tests/site.test.cjs` — ۲۹ آزمون ساختاری: مسیر ورودی، منابع محلی، نبود ایمیل/تلفن نمونه، لوگوها، لینک برنامه‌ریز، فرم تماس، اشتراک امن و کامل‌بودن ترجمه‌ها.
- `js/check-i18n.js` — بررسی کلیدهای ترجمهٔ پنج صفحهٔ اصلی در فارسی و انگلیسی.

## آزمون دستی مرورگری

| مورد | انتظار |
| --- | --- |
| سرفصل اصلی صفحهٔ خانه | در عرض‌های ۳۶۰ تا ۱۹۲۰ پیکسل یک‌خطی می‌ماند (فارسی و انگلیسی) |
| کلید زبان | متن‌ها، عنوان تب و `alt` تصاویر عوض می‌شود؛ پس از بازخوانی صفحه حفظ می‌شود |
| کلید تم | پس‌زمینه تیره/روشن می‌شود و لوگوی مناسب همان تم نمایش داده می‌شود |
| منوی موبایل (زیر ۹۸۰ پیکسل) | از کنار باز می‌شود، با Escape بسته می‌شود و فوکوس به دکمهٔ منو برمی‌گردد؛ اسکرول افقی وجود ندارد |
| صفحه‌های درباره، خدمات، نمونه‌کار، تماس | بدون خطای کنسول و بدون منبع گم‌شده بارگذاری می‌شوند |
| فیلتر نمونه‌کارها و مودال | فیلتر کار می‌کند؛ بستن مودال فوکوس را به کارت برمی‌گرداند |
| اسلایدر نظرات | دکمه‌های قبلی/بعدی و نقاط اسلاید را عوض می‌کنند |
| فرم تماس | ارسال چیزی به بیرون ندارد؛ خطاها با پیام فارسی و `aria-invalid` نمایش داده می‌شوند؛ متن ساخته‌شده قابل کپی است |
| جست‌وجوی پرسش‌ها | عبارت ناموجود پیام «پرسشی با این عبارت پیدا نشد» را نشان می‌دهد |
| برنامه‌ریز | تغییر نوع/امکانات/مقیاس برآورد را به‌روز می‌کند؛ پیش‌نویس پس از بازخوانی می‌ماند؛ لینک اشتراک فقط انتخاب‌ها را برمی‌گرداند |
| لینک اشتراک نامعتبر | پیش‌نویس محلی حفظ می‌شود و پیام خطا نمایش داده می‌شود |
| چاپ برنامه‌ریز | فقط خلاصهٔ برآورد چاپ می‌شود؛ فرم و هدر پنهان‌اند |
| فایل ورودی در پوشهٔ پروژه | با بازکردن `index.html` ریشه، صفحهٔ اصلی سایت باز می‌شود؛ حتی بدون جاوااسکریپت |
| بدون جاوااسکریپت | محتوای صفحه‌ها قابل مشاهده است؛ فرم تماس غیرفعال و راهنمای فعال‌سازی نمایش داده می‌شود |
| اشتراک از فایل محلی | مسیر دستگاه کپی نمی‌شود و پیامی برای استفاده از نسخهٔ آنلاین نمایش داده می‌شود |
| کنسول و شبکه | بدون خطا و بدون درخواست خارجی |

## نتیجهٔ آخرین اجرا

- Node: ۲۹ از ۲۹ آزمون موفق.
- Playwright (Chrome): ۳۵ از ۳۵ بررسی سرور محلی و ۱۶ از ۱۶ بررسی فایل محلی موفق.
- مسیر فایل ریشه با جاوااسکریپت روشن و خاموش، فرم بدون جاوااسکریپت یا با فایل اسکریپت مسدود، و اشتراک محلی و HTTP بررسی شدند.
- پویش عرض ۳۶۰–۱۹۲۰: سرفصل خانه یک‌خطی، بدون اسکرول افقی.
