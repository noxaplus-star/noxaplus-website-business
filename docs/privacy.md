# حریم خصوصی / Privacy

**آخرین به‌روزرسانی: ۱۸ نوامبر ۲۰۲۶ — نسخهٔ ۱.۰.۱**

## فارسی

این وب‌سایت یک قالب ایستا و نمایشی است و هیچ سرور، پایگاه داده یا سرویس تحلیلی ندارد.

- **فرم تماس:** هیچ اطلاعاتی ارسال نمی‌شود. متن پیام فقط در همان صفحه ساخته می‌شود تا کاربر خودش آن را کپی و از راه دلخواه ارسال کند. تا زمانی که صفحه باز است، متن در فیلدها باقی می‌ماند.
- **برنامه‌ریز پروژه:** محاسبات کاملاً در مرورگر انجام می‌شود. انتخاب‌ها در `localStorage` با کلید `noxaplus_planner_draft_v1` روی همان دستگاه ذخیره می‌شوند و با «پاک‌کردن پیش‌نویس» حذف می‌شوند.
- **لینک اشتراک برنامه‌ریز:** فقط نوع پروژه، امکانات و مقیاس را در بخش hash نشانی نگه می‌دارد؛ نام، ایمیل، شماره تماس یا متن پیام در آن نیست. hash به سرور فرستاده نمی‌شود. هنگام بازکردن فایل محلی، اشتراک لینک غیرفعال است تا مسیر دستگاه کپی نشود؛ از نسخهٔ آنلاین استفاده کنید.
- **ترجیحات:** زبان و تم در `localStorage` با کلیدهای `noxaplus_lang` و `noxaplus_theme` نگه داشته می‌شوند.
- **کوکی و ردیابی:** هیچ کوکی، پیکسل ردیابی یا اسکریپت تحلیلی استفاده نمی‌شود.
- **منابع خارجی:** فونت وزیرمتن و همهٔ تصاویر به‌صورت محلی میزبانی می‌شوند؛ در حالت عادی درخواستی به دامنهٔ شخص ثالث ارسال نمی‌شود.
- **میزبانی:** در نسخهٔ منتشرشده روی GitHub Pages، خود GitHub ممکن است گزارش‌های دسترسی (مانند نشانی IP) را طبق سیاست حریم خصوصی خود نگه دارد.

پیش از استفادهٔ تجاری، اطلاعات تماس واقعی و در صورت نیاز سرویس ارسال فرم را جایگزین کنید و این متن را به‌روز کنید.

## English

This is a static, demonstrative template with no server, database, or analytics service.

- **Contact form:** nothing is sent. The message is assembled in the page for the visitor to copy and send through a channel of their choice.
- **Project planner:** all calculations run in the browser. Choices are stored only on the device under the `noxaplus_planner_draft_v1` localStorage key and can be erased with “Clear draft”.
- **Share link:** the URL hash contains only project type, features, and scope — no name, email, phone, or message. Hashes are not sent to the server. When opened as a local file, sharing is unavailable to avoid copying the device's file path; use the online version.
- **Preferences:** language and theme are stored under `noxaplus_lang` and `noxaplus_theme`.
- **Cookies and tracking:** no cookies, tracking pixels, or analytics scripts.
- **External resources:** the Vazirmatn font and all images are self-hosted; no third-party requests in the default setup.
- **Hosting:** on GitHub Pages, GitHub may retain access logs under its own privacy policy.
